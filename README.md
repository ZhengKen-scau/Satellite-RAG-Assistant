## 🌟 核心特性

### 📚 **智能文档问答系统**
- **动态文件上传**: 每次提问可上传不同文件，实现针对性问答
- **全格式支持**: 
  - **文档**: PDF、TXT、DOCX、Markdown、CSV、JSON
  - **遥感影像**: GeoTIFF、ERDAS IMG、ENVI HDR/BIL、NetCDF、HDF5
  - **矢量数据**: Shapefile、GeoJSON、KML/KMZ、GPX
  - **图像**: JPG、PNG、BMP、GIF
- **专业领域适配**: 专为卫星遥感领域优化的回答风格

### 🎨 **现代化用户界面**
- **专业UI设计**: 直观的文档气泡悬浮预览，带专业图标标识
- **响应式布局**: 完美适配桌面和移动设备
- **流畅交互**: 平滑动画和即时反馈，提升用户体验

### 🧠 **高级AI能力**
- **长文本生成**: 支持长达2000 tokens的专业回答
- **语义检索**: ChromaDB向量数据库实现精准上下文匹配
- **本地大模型**: 基于Ollama运行qwen2.5:3b等开源模型
- **中文强制输出**: 确保回答使用简体中文，符合国内需求

### ⚡ **企业级架构**
- **配置驱动**: 所有参数通过.env文件管理，无硬编码
- **错误容错**: 完善的异常处理和用户友好提示
- **性能优化**: 缓存机制、延迟加载、资源释放
- **安全考虑**: 本地部署保障数据隐私

## 🚀 快速开始

### 系统要求
- **操作系统**: Windows 10/11, macOS, Linux
- **Python版本**: 3.9 或更高版本
- **内存**: 建议8GB以上（大模型运行需要）
- **磁盘空间**: 至少10GB可用空间

### 一键部署
```bash
# 1. 克隆项目
git clone https://github.com/your-username/Satellite_RAG_Assistant.git
cd Satellite_RAG_Assistant

# 2. 安装依赖
pip install -r requirements.txt

# 3. 安装Ollama (Windows示例)
# 下载: https://ollama.com/download/OllamaSetup.exe

# 4. 下载推荐模型 (~2GB)
ollama pull qwen2.5:3b

# 5. 启动应用 (自动处理端口冲突)
python run_simple.py
```

### 访问应用
打开浏览器访问: **http://127.0.0.1:8000**

## 🏗️ 项目架构详解

```
Satellite_RAG_Assistant/
├── app/                    # FastAPI核心应用
│   ├── main_final.py      # API入口 (标准化接口)
│   └── config.py          # 配置管理 (环境变量驱动)
├── core/                  # AI核心引擎
│   ├── llm_handler.py     # 大模型处理器 (统一接口)
│   ├── rag_chain.py       # RAG链实现 (检索+生成)
│   ├── prompt_manager.py  # 提示词管理 (专业模板)
│   └── vector_store.py    # 向量存储 (ChromaDB封装)
├── frontend/              # 用户界面
│   ├── index.html         # 响应式页面
│   ├── app.js            # 原生JavaScript逻辑
│   └── style.css         # 专业UI样式
├── scripts/               # 辅助工具
│   ├── download_model.py  # 模型管理工具 (用户友好)
│   └── manage_models.py   # 模型清理工具
├── storage/               # 数据存储 (自动生成)
│   ├── chroma_db/        # 向量数据库
│   └── cache/            # 缓存文件
└── tests/                 # 测试用例 (可扩展)
```

### 📊 技术栈亮点
| 组件 | 技术选型 | 选择理由 |
|------|----------|----------|
| **Web框架** | FastAPI | 高性能、自动生成API文档、类型安全 |
| **前端** | 原生HTML/JS | 轻量级、无构建步骤、易于理解 |
| **向量DB** | ChromaDB | Python友好、本地部署、简单易用 |
| **大模型** | Ollama + qwen2.5:3b | 中文优化、本地运行、开源免费 |
| **嵌入模型** | sentence-transformers | 高质量、离线可用、社区活跃 |

## 🔧 自定义与扩展指南

### 修改默认模型
```bash
# .env 文件
LLM_MODEL=llama3.2:3b
```

### 调整回答长度
```bash
# .env 文件
LLM_MAX_TOKENS=3000  # 默认2000
```

### 添加新文件格式
1. 在 `core/document_processor.py` 中添加解析逻辑
2. 在 `frontend/app.js` 中添加文件图标
3. 更新 `README.md` 中的支持格式列表

### 扩展提示词风格
修改 `core/prompt_manager.py` 中的模板，支持更多专业场景。
